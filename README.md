# Government Complaints Portal

A modern, secure, and performant React application for government complaints management.

## 🚀 Features

- **Secure Authentication** - Login and registration with robust validation
- **Performance Optimized** - 50-100% faster rendering with Million.js
- **Enterprise Security** - XSS protection, rate limiting, input sanitization
- **Responsive Design** - Mobile-first approach with Tailwind CSS
- **Production Ready** - Error boundaries, code splitting, lazy loading

## 🛠 Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Performance**: Million.js
- **Validation**: Custom security utilities
- **Build Tool**: Vite

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/ABD-Mohamad/gov-complaints-portal.git

# Navigate to project directory
cd gov-complaints-portal

# Install dependencies
npm install

# Start development server
npm run dev
